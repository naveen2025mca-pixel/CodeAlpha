# CodeAlpha Data Analytics Internship

## 📊 Project Overview

This repository contains the projects completed as part of the CodeAlpha Data Analytics Internship.

The projects demonstrate practical skills in web scraping, exploratory data analysis, data visualization, data cleaning, statistical analysis, and insight generation using Python.

The dataset used in these projects was collected from the public website **Books to Scrape** and analyzed to identify useful patterns and relationships.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Requests
- BeautifulSoup
- Google Colab
- Jupyter Notebook
- GitHub

---

## 📁 Completed Tasks

### 🔹 Task 1 — Web Scraping

**Folder:** `Task1_Web_Scraping`

In this task, data was extracted from the Books to Scrape website using Python.

**Tools & Libraries:**
- Requests
- BeautifulSoup
- Pandas

**Data Collected:**
- Book Name
- Price
- Rating

The scraped data was cleaned and stored as a structured dataset for further analysis.

---

### 🔹 Task 2 — Exploratory Data Analysis (EDA)

**Folder:** `Task2_EDA`

This task focuses on understanding and analyzing the scraped book dataset.

**Activities Performed:**
- Explored dataset structure
- Checked variables and data types
- Checked missing values
- Generated descriptive statistics
- Asked meaningful analytical questions
- Identified trends and patterns
- Analyzed relationships between price and rating
- Detected price outliers using the IQR method
- Checked duplicate records and data quality
- Summarized key insights

---

### 🔹 Task 3 — Data Visualization

**Folder:** `Task3_Data_Visualization`

This task transforms the analyzed data into meaningful visualizations.

**Visualizations Created:**
- Book Price Bar Chart
- Rating Distribution Chart
- Price vs Rating Scatter Plot
- Book Price Distribution Histogram
- Price and Rating Correlation Heatmap

These visualizations help communicate patterns and insights clearly and support better data interpretation.
